**▶️ Running a Program**

Clone the repository:

```bash
git clone https://github.com/your-username/Python-Repository.git
```

Navigate to the project:

```bash
cd Python-Repository
```

Run any Python file:

```bash
python filename.py
```

or

```bash
python3 filename.py
```
